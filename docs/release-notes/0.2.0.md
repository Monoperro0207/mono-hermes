- **UI updated to Hermes 0.21.5 (`158fd63`)**, the current upstream `main`. The bridge follows the new
  `window.hermesDesktop` contract: keep-awake now supports the upstream modes (off, while a turn is
  running, always) and the screen is held awake per the chosen mode.
- Tested against a Hermes 0.21.5 server at both the new commit (`158fd63`) and the previous one (`10c6188`), so
  you do not need to update your server. The in-app notice appears if your server's version differs; an older
  server may still work fine.
- Fixed the live tool-call ticker rows on touch screens, stuck tool groups, the git rail layout, and the
  terminal pane (hidden on touch, where it cannot work) (from 0.1.1 and 0.1.2).
- **Security documentation:** a Security section in the README (threat model, transport policy, what is
  stored on the device, permissions) and a `SECURITY.md` with the private reporting policy.
- **Build provenance:** the release APK now has a signed build provenance attestation. Verify with
  `gh attestation verify <apk> -R Monoperro0207/mono-hermes`.
