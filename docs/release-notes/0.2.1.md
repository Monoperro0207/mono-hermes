- **Fixed the layout breaking after rotating the phone** (closes #2). Opening the right panel in
  landscape and turning the phone back to portrait left an empty column on the right that squeezed the
  chat until the app was restarted. The cause was the desktop Terminal pane: the phone cannot run it, so
  it was only hidden visually, but the layout still reserved its column. It is now removed from the
  layout entirely, so the chat takes the full width again at every screen size and orientation.
- New rotation checks: a `rotation` scenario in the UI audit and `ui-audit/device-rotation.mjs`, which
  rotates the real emulator/phone through idle, sidebar, right panel, keyboard, live turn and Settings
  states at phone, Fold cover, Fold inner and tablet sizes.
- **Build provenance:** the release workflow attests the release APK; the attestation becomes active
  (and verifiable with `gh attestation verify <apk> -R Monoperro0207/mono-hermes`) once the repository
  is public.
