- **Hermes 0.22.0.** The app now runs the Hermes 0.22.0 desktop UI (was 0.21.5). Update the server on your PC
  with `hermes update` to match; an older server still works and the app shows a notice.
- **No more reconnecting every time you switch apps.** Android 15 and later cut a backgrounded app's network after
  about 5 seconds, which dropped the connection to your server on every app switch. Mono Hermes now keeps it open
  while a turn is running and for 5 minutes after leaving, so replies keep streaming, the "turn finished"
  notification arrives, and coming back is instant. A silent notification shows while it does (only after about
  10 seconds away). New permissions: `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_DATA_SYNC`.
- **Large photos upload.** Photos are shrunk to 2560 px on the long edge before upload, in their own format.
  A 20 MB camera photo used to fail with "too large to upload to the remote gateway" (or time out over mobile
  data); it now goes up as about 1 MB. Location and other EXIF metadata are removed. Attach a photo as a file
  to send the original.
- **In-app browser.** The Browser pane (and the agent's preview tools) works on the phone, in a separate, hardened
  WebView.
- Verify the download as before:
  `gh attestation verify mono-hermes-0.3.0-release.apk -R Monoperro0207/mono-hermes`
