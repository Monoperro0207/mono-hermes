- **Hard limits while streaming, and DNS-validated fetches**, following an external security review. Same Hermes
  UI as 0.2.4 (tested against Hermes 0.21.5); the Android bridge, a new native plugin and the docs changed.
- **Downloads are capped while they stream.** A new native plugin (`BoundedHttp`, OkHttp) replaces the
  WebView/`CapacitorHttp` path for link titles, media and file saves, so a cap can no longer be bypassed by a
  server that lies about `Content-Length` or answers a `HEAD` differently. Link titles read at most 64 KB,
  media is aborted at 64 MB, saved gateway files at 1 GiB (with a free-space check first) and saved images at
  32 MB. An oversized download is cut off mid-transfer.
- **DNS rebinding is closed for link titles and image saves.** For public fetches the app resolves the host
  itself, refuses it if any answer is non-public (loopback, LAN, Tailscale `100.64.0.0/10`, link-local, IPv6 ULA,
  and IPv4-mapped, NAT64 or 6to4 forms that embed a private address) and connects only to the addresses it
  validated. No system proxy is used, and at most 3 redirects are followed, each one re-validated.
- **Strict media cache.** Media is downloaded once into a single in-memory copy (the temporary file is
  deleted). The Blob cache stays within 128 MB and 24 entries; only files playing at that moment are exempt, and
  idle players are detached and download again when they play. File saves stream into the app cache, go through
  the share sheet, and old share copies are removed after an hour.
- **Recommended setup: Tailscale Serve.** Run `hermes serve --host 127.0.0.1` behind `tailscale serve --bg 9119`
  with `dashboard.public_url` set, and enter `https://<pc>.<tailnet>.ts.net` in the app. Nothing listens on
  your LAN and no firewall rule is needed. The previous all-interfaces setup is still supported as Option B in
  `docs/SETUP.md`, now with a mandatory "must not load from the LAN" check. New read-only
  `scripts/check-server-exposure.ps1` / `.sh` report what the Hermes port is listening on and flag firewall
  rules that open it beyond Tailscale. The connect screen's hint now mentions both forms of address.
- **CI tests the native Android path.** JVM unit tests cover the address policy, the DNS guard and the bounded
  fetcher, and an Android emulator smoke test signs in, plays media, checks that an oversized file is refused
  without crashing, and that private link titles and a loopback-resolving name are blocked. Releases are now only
  published after the whole CI workflow passes.
