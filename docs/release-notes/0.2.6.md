- **The native layer now owns every size limit**, following another external review. Same Hermes UI as 0.2.5
  (tested against Hermes 0.21.5); only the Android bridge, the native plugin and the docs changed.
- **Ceilings enforced natively.** The `BoundedHttp` plugin refuses any request above its own ceilings, whatever
  the web layer asks for: link titles 64 KB and at most 3 redirects, media 64 MB, public-web images 32 MB, saved
  gateway files 1 GiB. Non-finite, fractional or negative sizes are refused instead of being clamped.
- **Free-space check sized to the real file.** Saving a small file no longer requires 1 GB of free space: the
  check uses the announced size plus a 16 MB margin, and is repeated every 8 MB while writing, so a download
  without a size (or with a wrong one) still stops before the phone runs out of space.
- **Images from `data:` and `blob:` URLs follow the 32 MB limit too.** Their size is measured before any copy is
  made, so a huge in-memory image is refused instead of crashing the app.
- **Stricter address filter.** Link titles and public image downloads also refuse the IPv6 documentation range
  `3fff::/20` and the IETF protocol block `2001::/23` (benchmarking, Teredo, ORCHID).
- **Sturdier plugin.** An unexpected internal error now fails the request cleanly instead of leaving it waiting.
- **`main` requires a passing pull request.** Changes reach `main` only through a pull request whose CI passed;
  release tags cannot be moved or deleted.
- Verify the download as before:
  `gh attestation verify mono-hermes-0.2.6-release.apk -R Monoperro0207/mono-hermes`
